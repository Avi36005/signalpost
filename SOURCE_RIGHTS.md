# Source rights and retention

Verified 2026-09-13; company-owned-site policy revised 2026-09-13 (v2) after re-reading the fetched official source policy. The implementation still defaults to disabled for genuinely uncertain external rights (named third-party platforms, search, LLM, paid feeds); it defaults to enabled for a registry-linked company's own website, which the official policy lists as a preferred source category.

| Source | Enabled method | Basis / terms | Retention and fallback |
|---|---|---|---|
| Brønnøysundregistrene entities, public company roles, subunits, group links | Official unauthenticated REST endpoints | [Official API documentation](https://data.brreg.no/enhetsregisteret/api/dokumentasjon/en/index.html), NLOD 2.0; [dataset overview](https://www.brreg.no/bruke-data-fra-bronnoysundregistrene/datasett-og-api/) | Retain source evidence with attribution. Strip birth dates/personal identifiers from roles. Company-centric display only, no cross-company person search. HTTP 410 means do not redistribute removed records. |
| Regnskapsregisteret | Official numeric annual-account and available-year endpoints | [Brreg open API catalog](https://github.com/brreg/openAPI/blob/master/specs/API-catalog.ttl), NLOD-linked public accounts dataset | Retain exact JSON evidence, currency and periods. No inference from missing values. |
| Eligible universe | Official frozen challenge archive | [Participant brief](https://builderr.ai/starter-briefs/signalpost.md), supplied for challenge selection | Archive excluded from ZIP; exact selected manifest and hashes included. Reproducible download. |
| Company websites (registry-declared homepage, or a domain spelling the exact legal name when none is declared: home page and observed same-host careers/news/contact/about pages) | Static HTML/JSON-LD adapter, enabled by default; `config/sources.json` `domains` is an explicit per-domain denylist/override, not an allowlist | [Signalpost source policy](https://builderr.ai/starter-briefs/signalpost-sources.md) lists company-owned sources as preferred and does not require per-domain terms pre-review, unlike named third-party platforms | Robots.txt honoured (RFC 9309: a 4xx robots.txt means no restrictions; 5xx/unreachable blocks the host), SSRF-safe DNS-pinned fetch, exact-entity identity gate required before any claim is published, budget-capped. Retained evidence labelled `company_owned_public_source`. A domain can still be disabled individually via `config/sources.json`. |
| LinkedIn, Meta, Indeed, Glassdoor, X, YouTube, Google/Bing | Never fetched (hard-coded restricted-platform list). Profile **links** found on a verified company site are published as company-declared URLs without visiting the platform | [Signalpost source policy](https://builderr.ai/starter-briefs/signalpost-sources.md) and platform restrictions | No unofficial scraping. Licensed API integration and retention review required. |
| Search, LLM, JBOX, external paid feeds | Disabled | No provider credentials/budget/terms have been established for this entry | No paid calls made; no subscription assumed. |
| NAV arbeidsplassen | Not enabled | The public job feed (pam-stilling-feed, public token) has no per-employer or date query, and the website search API rate-limited a polite test on 2026-10-14 | Candidate for a future licensed/declared connector; employer `orgnr` in ads would allow exact-entity matching. |
| Brønnøysund announcements (w2.brreg.no/kunngjoring) | Not enabled | `robots.txt` disallows `/kunngjoring/` | Not crawled. |

Attribution: company registry/annual-account data contains information made available by Brønnøysundregistrene under NLOD 2.0. Company descriptions, if enabled later, are company-reported, not independent sentiment. NLOD does not override applicable privacy obligations; data minimization and removal handling still apply.
